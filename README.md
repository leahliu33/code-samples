
# Code Samples — Ziqian (Leah) Liu

In this folder, I include a short, curated set of code samples across
the three languages I use most for empirical research: **Python, R, and
Stata**. Each folder is self-contained and documents the question, the
approach, and the result. Datasets and outputs are not included. All
code here is my own work.

| Folder | Language | What it demonstrates |
|----|----|----|
| [`python/`](python/) | Python | Building a structured, geocoded dataset from \~27,000 lines of messy OCR text — parsing, cleaning, geocoding with API fallbacks, and a spatial (point-in-polygon) overlay. |
| [`r/`](r/) | R | Empirical analysis of Brazilian survey data — combining datasets, difference-in-proportions tests, and interaction regressions with controls, robust SEs, and formatted tables. |
| [`stata/`](stata/) | Stata | Replication and extension of a published panel study — balanced-panel construction, fixed-effects regression, a modern staggered DiD estimator (Callaway & Sant'Anna), and heterogeneity analysis with figures. |
